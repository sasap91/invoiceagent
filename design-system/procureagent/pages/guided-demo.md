# Guided demo overrides

These rules override the ProcureAgent master file for the default public route.

## Structure

1. Three-route navigation: **Guided demo**, **Overview**, **Evidence & methods**.
2. Outcome-led hero and three-item trust strip.
3. Four-step progress rail: read invoice, confirm and plan, approve simulation, match receipt.
4. Only the current step is expanded; completed work becomes a compact summary.
5. One primary action moves each step forward; a visible restart action provides an escape route.

## Visual proof

- Lead with the document result and exact business field, then expose every OCR token.
- Use distinct token categories and provenance text; unselected OCR words explicitly say they are not the target field.
- Keep answer-key evaluation separate from inference and label custom uploads “not scored.”
- Place the Dr AP / Cr Cash entry beside the simulated approval and show `$0.00` second cash deduction after receipt confirmation.

## Responsive behavior

- Four progress items stay in one row with abbreviated secondary text at narrow widths.
- Two-column image/control and evidence layouts collapse to one column below 900px.
- Trust items stack below 640px.
- Navigation may wrap but every route and restart remain visible without opening a drawer.
